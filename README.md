### 🕸 Set de Iconos para Tipos de Commits

| Icono | Tipo | Descripción | Ejemplo de Uso |
| --- | --- | --- | --- |
| ✨ | `feat` | Añade una **nueva característica** o funcionalidad a la aplicación. | `feat(auth): agregar inicio de sesión con Google` |
| 🐛 | `fix` | Soluciona un **error (bug)** en el código. | `fix(cart): corregir cálculo del total en el carrito` |
| 📝 | `docs` | Cambios exclusivos en la **documentación** (README, comentarios, etc.). | `docs(readme): actualizar instrucciones de instalación` |
| 🎨 | `style` | Cambios de **estilo o formato** que no afectan la lógica (espacios, punto y coma, etc.). | `style(header): formatear código con Prettier` |
| ♻️ | `refactor` | Refactorización del código que **no corrige bugs ni añade características**. | `refactor(api): simplificar lógica de peticiones HTTP` |
| ⚡️ | `perf` | Cambios orientados a **mejorar el rendimiento** (performance). | `perf(images): optimizar carga de imágenes en la galería` |
| 🧪 | `test` | Añadir, corregir o actualizar **pruebas** (tests unitarios, e2e). | `test(checkout): agregar pruebas para el flujo de pago` |
| 🔧 | `chore` | Tareas de **mantenimiento**, dependencias o configuración (webpack, vite, etc.). | `chore(deps): actualizar dependencias de npm` |
| 🚀 | `ci` | Cambios en los archivos de integración continua (GitHub Actions, GitLab CI, etc.). | `ci(workflow): añadir pipeline de despliegue automático` |
| ⏪ | `revert` | **Revierte** un commit anterior. | `revert: feat(auth): remover inicio de sesión con Google` |
